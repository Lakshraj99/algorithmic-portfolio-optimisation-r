# Algorithmic Portfolio Optimisation & Risk-Adjusted Return Analysis

This project implements an algorithmic portfolio optimisation system using real-world financial market data accessed via APIs. The objective is to construct optimal investment portfolios based on risk-adjusted performance metrics such as volatility and Sharpe ratio.

## Data Sources
- Yahoo Finance API: Historical daily stock price data
- FRED API: Risk-free interest rate (3-Month Treasury Bill)

## Tools & Technologies
- R (quantmod, tidyquant, PortfolioAnalytics)
- Power BI (R visuals)
- GitHub for version control

## Project Structure
- scripts/: R scripts for data ingestion, preprocessing, EDA, optimisation, and evaluation
- data/: Stored datasets (ignored in GitHub)
- powerbi/: Power BI files
